# 一拍之遥

入口：`/duet/`。橙灯执行本次输入，蓝灯执行上次输入，两盏灯到各自终点后过关。

## v7：教学关角色试验

仅教学关改为原创矢量庭院精灵：橙色种子帽、蓝色花苞帽，共同叶片饰物。蓝色观察/记住方向，下一次操作复现小跳步；双方开门时抬手回应，先到终点的橙色转身招手，两者抵达后欢呼再结算。动作由已有状态派生，撤销会同步恢复；减少动态效果偏好会关闭动画。正式11关仍使用灯角色和原规则。

角色状态回归：`node tests/duet-spirits.cjs`。试玩入口 `/duet/?learn=1&v=7`。

## v6：先玩懂配合

- 新用户先进入独立的五次操作练习：右、等、右、右、等。它使用正式引擎，展示延迟输入、等待、互相开门、先到终点后停住。
- `/duet/?learn=1` 可强制重放引导；`room` 保留原关卡，练习完成后可从第一关开始或返回原关卡。已有进度的人不自动进入引导。
- 练习不写正式关卡分数。`duet-learn-v1` 只保存 `done` / `skipped`；原 `duet-completed`、`duet-bests-v1` 保留。
- 正常关卡保持原来的 11 个布局、规则和星级：最优解三星，最优 +2 步内二星，最优 +4 步内一星，达到上限可撤销或重试。
- 文案统一使用橙灯/蓝灯、栅门/终点、方向/等待/步数。地图旁常驻蓝灯下次动作，动作时分别亮起角色说明；首次控制只突出当前要试的按钮。
- 正文与提示 16 px，主操作文字 16–17 px；次要信息按屏宽 12–15 px。SVG 内文字会随地图缩放，机关状态另有原生文本说明。
